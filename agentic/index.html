02 — CoreFusion / Autonomous developer platform

An agent that
owns the loop.

CoreFusion is an independently developed agentic developer platform. It imports a Git repository and gives an autonomous agent the tools to inspect, edit, execute, verify, and iterate inside isolated Docker sandboxes.

The central design decision is a strict sovereign-agent / stateless-executor split: the agent controls the plan and tool sequence; the backend exposes bounded primitives without embedding assumptions about the target language, framework, or build system.

Beyond the runtime, the platform includes repository code intelligence, scoped memory, a runtime MCP layer, collaborative review gates, and a commerce/LMS layer.

(01)

Sovereign runtime

Agent-owned planning and tool loop, cached system prefix, append-only context, file versioning, pre/post-tool hooks, and provider-agnostic model transport streamed over SSE.

(02)

Isolated execution

Go-powered Docker orchestration for container lifecycle, snapshot/revert, command execution, filesystem access, and live log streaming, with gRPC between runtime components.

(03)

Book-RAG intelligence

Repository-to-book indexing, workflow chains, cross-workflow links, keyword-to-symbol summaries, and a grep-versus-RAG decision layer that loads only relevant context.

(04)

Scoped memory

PostgreSQL/pgvector memory with hybrid dense/sparse retrieval, trigram and edit-distance tolerance, reciprocal-rank fusion, scoped access, and write validation.

(05)

Runtime MCP

Multi-transport integration, relationship-based authorization, agent-authored server lifecycle, discovery and auto-wiring, plus credential isolation so model context cannot read secrets.

(06)

Human-controlled actions

A shared propose → review → apply path for side effects across publishing, migration, integrations, and provisioning. Sensitive actions require an explicit human decision.

(07)

Real-time event layer

Elixir/Phoenix processes, channels and PubSub for multi-client presence and event delivery, with OTP supervision and persisted state.
